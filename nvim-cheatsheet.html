Neovim basics

Core motions, search & replace · keys are case-sensitive · press Esc to get back to normal mode
Learn these first
hjkl move i insert Esc normal mode w/b word forward / back f jump to char / search n/N next / previous * search word under cursor dd delete line u undo . repeat :w save :q quit

Move around

h / lLeft / right one character
j / kDown / up one line
w / bStart of next / previous word
eEnd of word
0 / ^ / $Line start / first text / line end
{ / }Previous / next paragraph
gthengTop of file
GBottom of file
42thenGGo to line 42
Ctrl-u / Ctrl-dHalf a page up / down
%Jump to matching bracket
Ctrl-o / Ctrl-iBack / forward in jump history

Any motion takes a count first: 3w moves three words.

Jump within the line

fthenxForward onto the next x
FthenxBackward onto the previous x
tthenxForward till just before x
TthenxBackward till just after x
;Repeat the last f/t jump
,Repeat it in the opposite direction

f only looks on the current line. 3f, lands on the third comma.

Insert text

i / aInsert before / after cursor
I / AInsert at line start / end
o / OOpen a line below / above
EscBack to normal mode

Search

/thentextSearch forward, Enter to jump
?thentextSearch backward
nNext match (same direction)
NPrevious match (opposite direction)
*Search forward for the word under the cursor
#Search backward for the word under the cursor
gthen*Like *, but also matches inside longer words
/thenEnterRepeat the previous search
:nohClear the highlighting

* matches whole words only: on count it skips counter. Searches wrap around the end of the file.

Replace the next occurrence

*1. Put the word under the cursor into the search
cthengn2. Change the next match; type the new text, Esc
.3. Repeat on the following match
nthen.Skip a match, then replace the one after it
dthengnDelete the next match instead

gn means “the next search match”. This is the quickest rename-as-you-go: review each hit, press . to accept, n to skip.

Replace & substitute

rthenxReplace one character with x
ROverwrite mode until Esc
:s/old/new/First match on this line
:s/old/new/gEvery match on this line
:%s/old/new/gEvery match in the file
:%s/old/new/gcSame, asking to confirm each one
:%s//new/gReuse the last search as old

At a c prompt: y replace · n skip · a all the rest · q stop.

Change & delete

xDelete the character under the cursor
dthendDelete the whole line
dthenwDelete to the start of the next word
D / CDelete / change to end of line
cthenwChange a word (deletes, then inserts)
ctheniwChange the whole word, cursor anywhere in it
>> / <<Indent / unindent the line
uUndo
Ctrl-rRedo
.Repeat the last change

Grammar: operator + motion. d=delete c=change y=yank, then any motion above — so d$, yf), c3w.

Text objects

iw / awInner word / word plus its space
i" / a"Inside quotes / including them
i( / i{Inside brackets / braces
ipInner paragraph
itInside an HTML/XML tag

Use them after an operator: di( empties the brackets, ci" retypes a string. i = inner, a = around.

Copy & paste

ythenyYank (copy) the line
ytheniwYank a word
p / PPaste after / before the cursor
"+yYank to the system clipboard
"+pPaste from the system clipboard

Deletes also fill the register, so dd then p moves a line.

Visual mode

vSelect by character
VSelect whole lines
Ctrl-vSelect a block (column)
motionExtend the selection
d / y / cDelete / yank / change the selection
> / <Indent / unindent the selection
EscLeave visual mode

Files, windows & tabs

:wSave
:qClose the window
:wq / ZZSave and close
:q!Close and throw the changes away
:e pathOpen a file
:sp / :vsSplit horizontally / vertically
Ctrl-wthenhjklMove to the window in that direction
:bn / :bpNext / previous buffer

Three useful workflows

  1. Rename a variable by hand: put the cursor on it, press *, then cgn, type the new name, Esc — now press . for each further occurrence and n to skip one.
  2. Rename it everywhere at once: * then :%s//newname/g — the empty pattern reuses what * searched for.
  3. Fix a string: anywhere inside the quotes, press ci" and type the replacement.

Escape hatch

EscLeave any mode; press it when lost
uUndo whatever just happened
:help fHelp for a key; :q closes it
:TutorBuilt-in 30-minute tutorial
:q!Get out without saving
Notation: “then” means a sequence, not simultaneous keys. Uppercase means Shift + key. Commands starting with : end with Enter. Stock Neovim keys, no plugins assumed · 2026-09-22
