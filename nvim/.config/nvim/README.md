# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## 📚 Configuration Documentation

- **[Customization Guide](.claude/LAZYVIM-CUSTOMIZATION.md)** - Advanced customization and troubleshooting

## Quick Links

- `:Lazy` - Plugin manager UI
- `:LazyExtras` - Browse and enable plugin extras
- `<Space>` - Open which-key (shows all keybindings)
- [LazyVim Keymaps](https://www.lazyvim.org/keymaps) - Official keymap reference
